# LinkWave + LockMachine

Projeto feito somente com HTML, CSS e JavaScript.

A descrição completa do projeto está no [README da raiz do repositório](../README.md). Este arquivo traz só as instruções rápidas de uso.

## Como abrir

1. Abra esta pasta no VS Code.
2. Instale a extensão **Live Server**.
3. Clique com o botão direito em `index.html`.
4. Escolha **Open with Live Server**.

Não é necessário instalar Node.js, banco de dados, PHP ou TypeScript.

## Organização

```text
index.html                         entrada do projeto
institucional/index.html           site da LinkWave
institucional/projetos.html        apresentação do projeto em destaque
institucional/style.css            visual da LinkWave
institucional/script.js            menu e animações da LinkWave
lockmachine_app/sobre.html         apresentação do LockMachine
lockmachine_app/tela_de_login.html login demonstrativo
lockmachine_app/dashboard.html     dashboard demonstrativo
lockmachine_app/style.css          visual do LockMachine
lockmachine_app/script.js          menu, login e data do dashboard
```

## Login de demonstração

Preencha os campos com qualquer e-mail válido e qualquer senha. Não existe autenticação real nesta fase: o formulário apenas encaminha para o dashboard de demonstração.
